# Simple SpeedDial

A clean, lightweight browser new-tab speed dial extension with organized bookmark groups, live search, customizable themes, multi-device sync, automatic backups, and maintenance tools.

## Install

- **Firefox Add-ons:** [Simple Dial for Firefox](https://addons.mozilla.org/en-US/firefox/addon/simple-dial/)
- **Microsoft Edge Add-ons:** [Simple SpeedDial for Edge](https://microsoftedge.microsoft.com/addons/detail/simple-speeddial/apbaccnojalophdpgohmbappaehdkljo)

## Features

- **Groups & Bookmark Tiles** — Organize bookmarks into tabbed groups with emojis or custom icons, drag-and-drop ordering, hover notes, custom tile colors, and automatic tile colors extracted from favicons.
- **Instant Search** — Search bookmarks across groups directly from the new tab bar.
- **Themes & Appearance** — Switch between Dark and Light modes, built-in seasonal themes (**Spring**, **Summer**, **Autumn**, **Winter**), or load your own custom CSS from a file or URL. Customize background images, tile transparency, tile/group sizes, and date/time display.
- **Synchronization** — Sync bookmarks via built-in browser sync, Direct HTTP/HTTPS endpoints, or WebDAV with optional credential encryption and configurable auto-sync intervals.
- **Backups & Import/Export** — Automatic scheduled local backups with retention limits, manual backup snapshots, JSON and NETSCAPE HTML import/export, and optional browser bookmarks folder sync.
- **HouseKeeper** — Soft-delete recovery and automatic cleanup, dead-link checking/highlighting, and automatic favicon refreshing.
- **Localization** — Supports English, Czech, German, Finnish, French, Dutch, Slovak, and Ukrainian.
