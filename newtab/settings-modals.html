Secrets Vault

Encrypts only sensitive secrets (such as widget API tokens) using AES-GCM. Unlocked keys stay in browser session memory only.

PBKDF2-SHA512 (210k) is faster on 64-bit systems (recommended default). Use PBKDF2-SHA256 (600k) if you are on a 32-bit system.

Optional: 0 = disabled, max 1440 min (24 hours).

Change Vault Password

PBKDF2-SHA512 (210k) is faster on 64-bit systems (recommended default); PBKDF2-SHA256 (600k) is for 32-bit. To switch KDF, select the new algorithm above and click Change Password (you may keep the same password when migrating KDF).
